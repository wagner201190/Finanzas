# Finanzas en Pareja

App web sencilla para llevar finanzas compartidas desde el navegador.

## Que incluye

- Registro de ingresos y gastos
- Resumen por persona
- Metas de ahorro compartidas
- Persistencia local con `localStorage`

## Como usarla

1. Abre `index.html` en tu navegador.
2. Registra movimientos y metas.
3. Los datos quedan guardados localmente en ese navegador.

## Nota

La app funciona sin backend. Si luego quieres, la siguiente mejora natural seria agregar:

- cuentas separadas y compartidas
- presupuestos mensuales
- exportacion CSV/PDF
- sincronizacion entre celulares
